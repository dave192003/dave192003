### 🔍 Project Highlights

**ID-Oto — Automated ID Photo Processing**

- Automated background removal and photo enhancement.
- Mamdani Fuzzy Inference System with triangular membership functions and 15 fuzzy rules.
- Automatic cropping for standard ID and passport photo dimensions.
- Printable photo sheet generation.
- Fuzzy logic analysis page for comparing original and processed images.
- Docker-based deployment with a Flask REST API and Nginx frontend.
